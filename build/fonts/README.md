# Build fonts

`NotoSansCJKsc-Regular.otf` is Noto Sans CJK SC Regular from the official
[notofonts/noto-cjk repository](https://github.com/notofonts/noto-cjk/blob/main/Sans/OTF/SimplifiedChinese/NotoSansCJKsc-Regular.otf).

`NotoSans.ttf` is the Noto Sans variable font distributed by the Nixpkgs
`noto-fonts` package from the official [Noto fonts project](https://github.com/notofonts/noto-fonts).
Its upstream Google Fonts source is
[`NotoSans[wdth,wght].ttf`](https://github.com/google/fonts/blob/main/ofl/notosans/NotoSans%5Bwdth%2Cwght%5D.ttf).

These fonts are used only while rasterizing deterministic social preview
images. Both are licensed under the SIL Open Font License 1.1. The Latin
font's upstream copyright notice and license are in `LICENSE-NOTO-SANS.txt`;
the CJK font's distributed license is in `LICENSE-OFL.txt`.
